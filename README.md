# Preparação Python para o Blind 75

Projeto de estudo para desenvolver a base necessária de Python e resolver, com profundidade, os problemas do **Blind 75** do [NeetCode](https://neetcode.io/practice?tab=blind75).

## Como funciona

O conteúdo é organizado em níveis progressivos. Cada nível apresenta apenas os conceitos necessários para liberar um novo conjunto de problemas, sempre com foco em prática, clareza e boas práticas de código.

O percurso vai de fundamentos da linguagem até estruturas de dados e algoritmos, incluindo listas, dicionários, técnicas de busca, recursão, árvores, grafos e programação dinâmica.

## Organização

```text
exercicios_python/   # Exercícios de preparação por nível
blind75/             # Problemas organizados por categoria
```

As soluções seguem a organização de categorias do Blind 75, como `arrays_hashing`, `two_pointers`, `graphs`, `trees` e `dp_1d`.

## Objetivo

Construir autonomia para resolver problemas de algoritmos em Python, entendendo o raciocínio, a complexidade e as escolhas de implementação por trás de cada solução.
